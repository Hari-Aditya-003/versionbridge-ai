02 / PATCH AUTHOR

Vultr Inference

The configured coding model receives the failing test output and the relevant source. The server validates its proposed change.

Disposable Docker sandboxes

Each baseline, verification, and probe runs in its own container. The workspace shows its ID and cleanup result.

Common questions

When would a team use VersionBridge?

Use it to investigate a failing dependency upgrade, compare test results, and hand a verified patch to a maintainer for review.

What can I repair?

Try pandas, Pydantic, an invoice calculation bug, or a seeded regression that the verifier should reject. Public imports require a small pytest repository compatible with the selected profile and the preinstalled sandbox dependencies.

Does it change my repository?

The patch applies to a temporary copy. Download the diff and decide whether to apply it to your project.
